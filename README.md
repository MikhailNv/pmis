# PMIS — Практические работы МУЛЬТИФАКТОР

Учебный репозиторий для практических работ по курсу управления ИТ-функцией на примере компании ООО «МУЛЬТИФАКТОР».

## Структура веток

| Ветка | Содержимое |
|---|---|
| `main` | Только этот `README.md` — описание репозитория и навигация |
| `passport` | `паспорт.md` — паспорт компании МУЛЬТИФАКТОР: бизнес, масштаб, направления, ограничения |
| `pw_1` | `практическая_работа_1.md` — отчёт по практической работе №1; `практическая_работа_1_сценарии.md` — план CTO по негативным сценариям с расчётами юнит-экономики и финальным вердиктом |
| `pw_2` | `практическая_работа_2.md` — отчёт по практической работе №2: пять гипотез роста выручки, одна — про ИТизацию. Каждая гипотеза описана одинаковыми девятью полями, с порогом, сроком проверки и наблюдением для отказа. Далее — отраслевой коридор, привязка к P&L, формула приоритета со счётом, разбор долгов ПР1 |
| `pw_3` | `практическая_работа_3.md` — отчёт по практической работе №3: перепроектированы три процесса под гипотезы 1, 5 и 3 из ПР2 — исполнение типового запроса на обслуживание (жёлтая зона с красным SLO-риском), выпуск с сертификацией LTS-версии (красная зона, цена риска 12–30 млн ₽/год) и перевод B2B-клиента на управляемый сервис. Для каждого — схема и таблица потерь до изменения, схема после с подсвеченными изменениями; каждое изменение привязано к потере и обслуживаемой гипотезе. Далее — ITIL 4, DORA, место агента, эффект и trade-off, лебеди 1–2 с capacity ledger, сертификацией и уведомлением B2G, новые допущения D34–D49 |
| `pw_4` | `практическая_работа_4.md` — отчёт по практической работе №4: дерево показателей, KPI и OKR с риском натягивания, паспорта метрик, экран руководства с потерями при свёртке и p50/p90, модель P&L и мощности со сверкой 2024→2025, прогноз до наблюдения, три сценария, бюджет с окупаемостью и критериями остановки, новые допущения D50–D63 |

## Как работать

1. Переключитесь на нужную ветку: `git checkout <branch_name>`
2. Изучите файлы в соответствии с таблицей выше
3. Для полного контекста идите по порядку: `passport` → `pw_1` → `pw_2` → `pw_3` → `pw_4`.
