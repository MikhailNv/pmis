# PMIS — Практические работы МУЛЬТИФАКТОР

Учебный репозиторий для практических работ по курсу управления ИТ-функцией на примере компании ООО «МУЛЬТИФАКТОР».

## Структура веток

| Ветка | Содержимое |
|---|---|
| `main` | Только этот `README.md` — описание репозитория и навигация |
| `passport` | `паспорт.md` — паспорт компании МУЛЬТИФАКТОР: бизнес, масштаб, направления, ограничения |
| `pw_1` | `практическая_работа_1.md` — отчёт по практической работе №1; `практическая_работа_1_сценарии.md` — план CTO по негативным сценариям с расчётами юнит-экономики и финальным вердиктом |
| `pw_2` | `практическая_работа_2.md` — отчёт по практической работе №2: пять гипотез роста выручки, одна — про ИТизацию. Каждая гипотеза описана одинаковыми девятью полями, с порогом, сроком проверки и наблюдением для отказа. Далее — отраслевой коридор, привязка к P&L, формула приоритета со счётом, разбор долгов ПР1 |
| `pw_3` | `практическая_работа_3.md` — отчёт по практической работе №3: перепроектированы два процесса под гипотезы 1 и 5 из ПР2 — исполнение типового запроса на обслуживание (жёлтая зона) и выпуск с сертификацией LTS-версии (красная зона, цена риска 12–30 млн ₽/год). Для каждого — схема и таблица потерь до изменения, схема после с подсвеченными изменениями; каждое изменение привязано к потере и обслуживаемой гипотезе. Далее — практики ITIL 4 (только меняющиеся), метрики DORA, место агента по четырём вопросам с ценой приёмки, эффект на принятый результат и trade-off, новые допущения D34–D38 |

## Как работать

1. Переключитесь на нужную ветку: `git checkout <branch_name>`
2. Изучите файлы в соответствии с таблицей выше
3. Для полного контекста идите по порядку: `passport` → `pw_1` → `pw_2` → `pw_3`.
